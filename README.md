## <img src="https://api.iconify.design/lucide/user.svg?color=%232F81F7" width="24" height="24" align="center" /> About Me

I'm a Software Engineer who enjoys building practical software solutions and taking ownership of them from development to deployment and maintenance. I work across backend development, APIs, databases and frontend integration, primarily using **Python, Java, JavaScript/TypeScript and Linux/Bash**.
