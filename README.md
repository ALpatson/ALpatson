## Featured Work 💻

### Miss Library - Library Management System
**NestJS** | **React** | **TypeScript** | Backend Architecture | JUNIA M1 Project

A full-stack library management system built as part of the Master's curriculum. My focus was on designing a robust, scalable backend using Domain-Driven Design principles with NestJS and TypeORM.

**Backend Highlights:**
- Domain-Driven Design architecture with clear separation of concerns
- RESTful API with comprehensive endpoints for books, authors, clients, and sales
- Complex business logic (purchase tracking, analytics, statistics)
- Efficient database queries and ORM optimization
- Exception handling and validation across all layers
- Layered architecture: Controller → Service → Repository pattern

**Tech Stack:**
- Backend: NestJS 10.x, TypeORM, SQLite, TypeScript
- Frontend: React 18, Vite, Ant Design (built by team)

**Team:** Alpatson Cobbina Siaw (Backend Lead), Josephine Ama Gyanewah Gyasi, Kwabena Anokye

### Tales of Knights - Text-Based RPG
**Java** | System Design & Game Architecture | Advanced OOP

A comprehensive text-based RPG showcasing sophisticated backend architecture and system design. This project demonstrates mastery of Object-Oriented Design through complex inheritance hierarchies, polymorphic behavior, and encapsulation.

**Backend Architecture:**
- Multi-level inheritance hierarchy with abstract base classes (Character, Fighter, Item, Place)
- Polymorphic combat system with tactical decision logic
- Complex state management for game progression and NPC interactions
- In-game economy system with inventory management and trading
- Exception handling and validation throughout

**Advanced OOP & System Design:**
- Abstract classes enforce contract-based design
- Interface implementation (Aggression for combat, Consumable for items)
- Proper encapsulation with validation in setter methods
- Polymorphic methods adapted for different character types
- Clean separation between game logic and presentation

**Built With:** Java, NetBeans

→ [View Repository](https://github.com/ALpatson/Tales-of-Kinghts-2)
